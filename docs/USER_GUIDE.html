Hatua

The Hatua user guide

Hatua helps Kenyan teachers and parents see how each learner is doing, term by term, from Grade 4 to Grade 9. This guide shows you every step, with pictures.

1. What Hatua does

A child's results are written down every term, but they are spread across many files and many teachers. Hatua puts them in one place, so a teacher and a parent can see the long view: what is going up, what is going down, and what has stayed strong since Grade 4.

  • Teachers upload each term's Excel results file, approve it, and see alerts when a learner needs help.
  • Parents sign in and see their own child's results, days in school, and messages from the class teacher.
  • The Hatua assistant answers questions in simple English or Kiswahili. It always asks one short question first, so the answer fits what you need.

Hatua never ranks children, never calls a child "weak" or "bright", and never picks a senior school pathway for a child. A teacher always decides.

Levels follow the CBC: EE Exceeding, ME Meeting, AE Approaching, BE Below Expectations.

3. Put Hatua on your computer

Hatua is free and open source. Download it from the Hatua download page.

Your computerDownload this file
Mac with an Apple chip (M1, M2, M3 or newer)Hatua-Mac-Apple-chip.zip
Older Mac with an Intel chipHatua-Mac-Intel.zip
Windows 10 or Windows 11Hatua-Windows.zip

Not sure which Mac you have? Click the Apple menu, then About This Mac. It says "Chip: Apple M..." or "Processor: Intel".

On a Mac

  1. Open your Downloads folder and double-click the zip file. A Hatua folder appears.
  2. Drag the Hatua app into your Applications folder.
  3. The first time only: right-click Hatua (or Control-click) and choose Open. The Mac asks if you are sure. Press Open.
  4. After that, open Hatua the normal way.
Why does the Mac ask? Hatua is free and does not come from the App Store, so the Mac checks with you once. This is normal for free school software.

On Windows

  1. Open your Downloads folder. Right-click the zip file and choose Extract All, then Extract.
  2. Open the new Hatua folder, then the Hatua folder inside it, and double-click Hatua.exe.
  3. If Windows says "Windows protected your PC", press More info, then Run anyway. This happens once.
  4. Tip: right-click Hatua.exe and choose Send to > Desktop (create shortcut).

What happens when Hatua opens

A small Hatua window opens. The first time, it says "Getting Hatua ready" for about 20 seconds while it makes the practice school. Then Hatua opens in your web browser. The small window has three buttons: Open Hatua, User guide and Stop Hatua. Closing the small window stops Hatua.

Your data stays on this computer. Hatua opens in the web browser, but it is not on the internet. The address is http://127.0.0.1, which means "this computer". No other computer can open it.

4. The AI helper (Qwen)

The Hatua assistant can use Qwen, a free AI that runs on your own computer. Without Qwen, Hatua still works: the assistant gives built-in answers to the common questions.

On the sign-in page, a box tells you what to do next. It changes as you go:

  1. Add the AI helper. Press Get Ollama. Ollama is the free program that runs Qwen. Download it, open the file, and follow its steps. It takes about two minutes.
  2. Come back to Hatua and press Check again.
  3. Get the AI helper. Press Download Qwen. Hatua asks Ollama to download Qwen. It is about 4.7 GB, once. A bar shows how far it is. You can use Hatua while it downloads.
  4. When the box turns green and says Qwen is ready, the assistant writes its answers with Qwen. It works without internet from now on.
Use good internet for the download. 4.7 GB is large. Use school Wi-Fi or a big data bundle. If the download stops, press the button again: it continues where it stopped.

A computer with 8 GB of memory or more works best. On a smaller computer, Qwen is slow; Hatua's built-in answers are always quick.

5. Signing in safely

  1. Choose I am a teacher or I am a parent.
  2. Teachers type their TSC member number. Parents type the parent number the class teacher gave them (it starts with P-).
  3. Type your PIN and press Sign in.

The first time: choose your own PIN

The PIN you are given works one time. Hatua then asks you to choose a PIN that only you know. Nothing opens until you do.

Hatua says no to PINs that are easy to guess, like 123456, 111111 or your own number.

Rules that protect you

  • After 5 wrong PINs, sign-in stops for 15 minutes.
  • If you do not use Hatua for 15 minutes, it signs you out and clears the screen.
  • Your number works in one place at a time. A new sign-in ends the old one.
  • My account shows every sign-in and every wrong PIN on your number. If you see one that was not you, change your PIN.

Forgot your PIN? Teachers ask the school's Hatua admin for a new one-time PIN. Parents ask the class teacher.

6. For teachers

After you sign in, you see five tabs: Today, School drive, My class, School calendar and Hatua assistant. You see only your own class.

The Today tab: what needs you

Today shows learners to watch and results files that need you. An early sign means a learning area fell two levels in one term. A pattern means several terms in a row.

Press Message for the parent to get a short, kind message in English or Kiswahili. Copy it and send it your usual way: SMS, WhatsApp, a call or a note. Then press I have told the parent. Hatua sends nothing by itself.

The School drive tab: one Excel file per term

Your class has a folder for Term 1, Term 2 and Term 3. Each folder holds one Excel results file. The cards at the top say if each term is In Hatua, Waiting for you, File missing or Not due yet.

To add a term's results: choose the term, choose your Excel file, and press Upload to the drive. Then press Check the file. Hatua shows how many rows are for your class, and how many are for another class (it leaves those for their teacher). Press Approve and add to Hatua.

The Excel file needs these columns in row 1: learner_id, grade, year, term, learning_area, level. score and task are optional. An empty template is in docs/templates/results_template.xlsx.

If a file is deleted, you are told

If someone deletes or moves an approved Excel file from a term folder, Hatua tells that class's teacher only, the next time they open Hatua or come back to its window. The card says which file is gone and the day you approved it. The results stay safe in Hatua. Put the file back, or upload it again, and the alert goes away.

If a term's results are late (past the due date, 7 days after the term closes) and no file is in the folder, Hatua tells you too.

The My class tab: one learner across the years

Tap a learner. You see the alerts, the report comment, what the records show, and the long view from Grade 4. Earlier grades were written by earlier teachers and are read only. Tap any round mark to see the record behind it.

Report comment: press Write a comment. If it sounds right, press the thumbs up, change a word if you like, and press Use this comment. If not, press the thumbs down, say why, and Hatua writes it again. Hatua learns from your thumbs.

Senior school pathway ideas (Grades 7 to 9)

For Grades 7 to 9, Hatua can show which strengths in the records relate to each senior school pathway: STEM, Social Sciences, and Arts and Sports Science. They are closed until you press Open pathway ideas. Hatua records your name and the time. Once you open them, the learner's parents can see them too.

Give a parent access

On a learner's page, find Parents who can see and press Give a parent access.

  1. Type the parent's full name and choose Mother, Father, Guardian and so on.
  2. If the parent already has a parent number (a brother or sister is at the school), type that number instead. One parent, one number.
  3. Press Make the parent number and PIN. Hatua shows a slip with the parent number and a one-time PIN. Print it or write it down. Hatua shows the PIN only now.
  4. Give the slip to the parent yourself, the way the school always checks who a parent is.

The list shows who can see the learner and when they last signed in. New PIN gives a parent who forgot their PIN a new one-time PIN. Remove stops their access at once.

The Hatua assistant

Press Hatua assistant. You can move the window, make it bigger or smaller, or make it fill the screen. Ask in English or Kiswahili.

The assistant always asks one short question first, with answers to tap. Then it answers, with the record numbers it used. Tap a record number to check it.

It never ranks learners. Ask "Who is the best in my class?" and it says no, kindly.

The School calendar tab

The 2026 term dates from the Ministry of Education, and the day each term's results are due in Hatua.

7. For parents

Sign in

  1. The class teacher gives you a slip with a parent number (like P-123456) and a one-time PIN.
  2. Open Hatua on the school computer or the computer where your school runs it. Choose I am a parent.
  3. Type your parent number and the one-time PIN. Hatua asks you to choose your own PIN. Keep it secret.

Your child's page

  • Newest results: each learning area's level, and if it went up or down since the term before.
  • Days in school: how many days your child came, out of the days the school was open.
  • From the class teacher: the report comment and messages the teacher sent you, in English or Kiswahili.
  • Senior school pathway ideas (Grades 7 to 9): only when the class teacher has shared them.
  • Every term since Grade 4: the long view. Tap a level to see the record.

If you have two or more children at the school, tap a name at the top to switch.

Ask the Hatua assistant

Press Hatua assistant and ask about your child: "How is Achieng doing?", "How can I help at home?", "When does the next term open?". It asks one short question first, then answers with the record numbers.

The assistant knows only your own child. It will not compare your child with others, and it will not tell you about another child.

8. How Hatua keeps children safe

WhoCan seeCan never see
Class teacherTheir own class, with each learner's full history from Grade 4Other classes
ParentTheir own child: approved results, days in school, the comment and messages the teacher shared, pathway ideas the teacher openedOther children, teacher notes, alerts the teacher has not raised, any ranking
The assistantThe same as the person askingAnything else
  • A teacher must approve each results file before Hatua uses it.
  • A teacher must open pathway ideas, with their name, before anyone sees them.
  • Every sign-in, approval and change is written to a log that cannot be changed without Hatua noticing.
  • Everything stays on the school's computer. Hatua does not send learner data to the internet, and Qwen runs on the same computer.
  • PINs are stored only as a secure code (a hash), never as the PIN itself.

9. For the school's Hatua admin

The download opens the practice school. Setting up your real school is a job for one person who is comfortable with spreadsheets and a terminal. It is done once.

  1. Install Python 3.9 or newer, download the Hatua source code from GitHub, and run pip install -r requirements.txt in its folder.
  2. Make a folder for your school, for example Hatua School, with a data/raw folder inside it.
  3. Put five CSV files there: learners.csv (the class list), teacher_assignments.csv (which teacher has which class), attendance.csv, teacher_notes.csv and records_2021_2026.csv (past results). The practice school's files show the columns.
  4. Load them, then add each teacher with a one-time PIN:
HATUA_HOME="Hatua School" python -m hatua setup
HATUA_HOME="Hatua School" python -m hatua teacher-add --id M-1234 --name "Jane Wanjiru" --one-time
HATUA_HOME="Hatua School" python -m hatua portal

On Windows, use set HATUA_HOME=Hatua School first. Teachers then add parents themselves, from each learner's page.

Before you use real learners' data, the school must agree to it in writing, and parents must be told. Read PRIVACY.md and docs/DPIA.md in the source code. Kenya's Data Protection Act, 2019 applies.
One computer at a time. Hatua runs on one computer, for example the school office computer. Teachers and parents use it there. It is not on the internet, so a parent cannot open it from home yet.
