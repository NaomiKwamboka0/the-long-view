FOR KENYAN SCHOOLS, GRADE 4 TO GRADE 9

See every learner's long view, not just this term.

Hatua puts each child's CBC results from Grade 4 onwards in one place. Teachers see who needs help early. Parents see how their own child is doing. Nothing leaves the school's computer.

Simple for teachers. Clear for parents.

Hatua does the slow work of joining up the years. A teacher always makes the decision.

One Excel file per term

Each class has a folder for Term 1, 2 and 3. The class teacher checks the file and approves it. If a file is deleted, that teacher is told.

Early signs, with proof

When a learner drops two levels, or slides over several terms, Hatua says so. Every claim shows the record behind it.

Parents see their own child

The class teacher gives each parent a number and a one-time PIN. A parent sees only their own child: results, days in school, and the teacher's messages.

An assistant that asks first

Ask in English or Kiswahili. It always asks one short question first, then answers with the record numbers. It never ranks children.

Safe by design

Children's records are sensitive. Hatua is built so the safe way is the only way.

  • Runs on the school's own computer. Learner data is never sent to the internet.
  • The AI, Qwen, runs on the same computer. It is free and open.
  • Each person has their own PIN. Easy PINs are refused. 5 wrong PINs lock sign-in for 15 minutes.
  • A teacher approves every results file, and opens pathway ideas with their name.
  • No rankings, no labels like "weak" or "bright", and no pathway is ever picked for a child.
  • Every action is written to a log that shows if anyone changed it.
